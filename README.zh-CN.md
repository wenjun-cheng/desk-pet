# 桌宠

[English](README.md) | **简体中文**

一个能打开 Claude Code 的 Windows 迷你桌宠。

![预览](docs/preview.zh-CN.png)

## 下载

1. 先安装 [Claude Code](https://code.claude.com/docs/en/quickstart)，确保在终端里能运行 `claude`
2. 到[最新版本](../../releases/latest)下载 `DeskPet-x.y.z-win64.zip`
3. 解压后双击 `DeskPet.exe`

如果 Windows 提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

## 功能

- 从屏幕底边探出头，鼠标靠近就跑出来
- 单击：切到已经打开的 Claude Code 窗口，没有就新开一个
- 双击：新开一个 Claude Code 窗口
- 可以拖到底边任何位置
- 全屏应用时藏起来，鼠标碰到它附近的底边就会出来
